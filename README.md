# KettleFarms static site

Framework-free, responsive and GitHub Pages ready.

## Expand it
The shared navigation/footer live in `assets/js/site.js`. To add a page, copy an HTML file and add one item to the `pages` array.

## GitHub Pages
Upload everything in this folder to the repository root, keep `index.html` at root, then enable Settings → Pages → Deploy from branch → main → /(root).

## Before launch
Replace social links, confirm email, add real farm photos, and connect the contact form if desired.
